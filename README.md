# ✅ To-Do List

Aplicação de lista de tarefas desenvolvida em **React** com **TypeScript**, 
a partir de um desafio de React com layout no Figma.

## 🚀 Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Contador de tarefas criadas e concluídas
- Estado vazio quando não há tarefas
- Interface fiel ao design do Figma

## 🛠️ Tecnologias

- React
- TypeScript
- CSS

## 🎨 Layout

O design do projeto está disponível no [Figma](https://www.figma.com/design/JScI51mc9u3Bi1RgDQ3KeR/ToDo-List-%E2%80%A2-Desafio-React--Community-).
